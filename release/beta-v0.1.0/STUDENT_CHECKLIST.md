# CLAN v0.1.0 beta — student checklist

Use a laptop (macOS arm64 / Windows x64) or an Android phone (arm64, Android 7.0+; so far run only on an Android 16 emulator), on the **same Wi-Fi** as your teacher
or study-group host. Allow about 40 minutes. Write `OK`, `FAIL` or `SKIP` and a short note per line, then give this file
to your teacher. CLAN never sends it anywhere.

Device: ____________ OS/version: ____________ Phone or laptop: ________ Date: ________

## A. Install
| # | Step | Result / note |
|---|---|---|
| A1 | Install (SETUP.md). Android: allow "install unknown apps" for your file app once | |
| A2 | Enter your name, roll number and device name (phone) / see My Space (laptop) | |
| A3 | Turn on airplane mode: Study, Notes and Diary still work. Turn it off again | |

## B. Join a CLAN
| # | Step | Result / note |
|---|---|---|
| B1 | Join a CLAN → type the 6-digit code from the host. (If the CLAN isn't found, also type the host address) | |
| B2 | Wait until the host approves you. You see the CLAN's name, files and chat | |
| B3 | Type a wrong code once on purpose: you are refused and nothing else happens | |

## C. In the CLAN
| # | Step | Result / note |
|---|---|---|
| C1 | Send a message to everyone; send one only to the host / one member; check who can see what | |
| C2 | Send a file (Study group) — in a Classroom you should *not* be able to send files | |
| C3 | Download a shared file; it opens and is complete | |
| C4 | Whiteboard: draw, add text/sticky; others see it. In a Classroom you can draw only after the teacher allows it | |
| C5 | When the host presents, you see the screen live | |

## D. Study on your own
| # | Step | Result / note |
|---|---|---|
| D1 | Study: create a course, a topic and a note; edit the note; it is still there after closing and reopening CLAN | |
| D2 | Diary: write an entry. It stays on this device unless you turn Diary sync on | |
| D3 | Inbox: save a link (phone: share a link from your browser to CLAN) | |

## E. Link your phone and laptop (needs both)
| # | Step | Result / note |
|---|---|---|
| E1 | Laptop: Me › My Devices → Link a new device → a code. Phone: Me › Open My Devices → type the code → Link | |
| E2 | Approve on the laptop. A note made on one device appears on the other after "Sync now" | |
| E3 | Edit the same note on both while one is offline → CLAN shows a conflict and lets you choose / keep both | |
| E4 | Unlink the phone on the laptop → the phone says it was unlinked and stops syncing | |

## F. Offline and reconnect
| # | Step | Result / note |
|---|---|---|
| F1 | While in a CLAN, turn Wi-Fi off for 20 s, then on: CLAN reconnects by itself and missed messages appear | |
| F2 | Close CLAN completely (swipe it away / quit) and open it again: your notes are there | |

## G. Problems and feedback
Laptop: Me › Beta feedback → Save feedback… (diagnostics only if you tick it; "Show exactly what's attached" first).
Phone: write it on this sheet. Never include passwords, private notes or Diary text.

**Before uninstalling the phone app:** uninstalling deletes everything CLAN stored on the phone (Android backup is off on
purpose, so it can't be restored later). Link and sync with your laptop first if you want to keep your study data.
