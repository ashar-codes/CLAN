## Explicit upcoming UI and platform requirements

Later BTC-2 stages must deliver group audio, one-to-one video, group video meetings/screen sharing and consent-based remote desktop control (Mac/Windows hosts; supported Mac/Windows/Android/iOS controllers). Reuse existing WebRTC, LiveKit and secure hosting; do not implement these in BTC-2A.

Cross-platform UI delivery must include fixed chat headers with audio/video actions and three-dot menus; consistent create/edit/delete/archive controls for user-created content; Smart Timetable image attachment, editable extraction and current-class information; and native functionality/accessible UI on macOS, Windows, Android and iOS. BTC-2E requires hardware verification and updated compatible installers after earlier stages pass. Security, consent, authenticated host fencing and offline operation remain mandatory.
