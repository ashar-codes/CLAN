## File transfer (Milestone 2)

Run: `pnpm benchmark` (also runs the join benchmark above). Real-Wi-Fi measurements: see "Real-network benchmark" below.

<!-- bench:files:start -->
Generated by `pnpm benchmark` on 2026-10-07T02:14:14.532Z.

**Environment.** darwin 25.5.0, Apple M1 Pro ×8, 17 GB RAM, Node v24.19.0. Server bound to `192.168.18.52` (this machine's LAN interface) in its own process; all simulated students run in one other process on the **same machine**.

**Method.** Each student joins (open policy) and downloads with the production client path: streamed HTTP, incremental SHA-256, `.partial` file, verify, atomic rename. Each scenario runs 3× and the median-elapsed run is shown. Server CPU = server process CPU time ÷ wall time (100% = one core). Peak RSS = server process high-water mark so far (includes startup, importing the 1/10/100 MB test files, and earlier scenarios).

**Limitations.** Loopback-speed networking, no radio contention, no packet loss. Client hashing for all students shares one process, so many-client rows are partly client-bound. **These numbers do not demonstrate Wi-Fi performance**; use `tools/sim/lan-bench.ts` with real devices for that.
